# Isometric objects (Isoflow)

The 36 icons of the `isoflow` collection in `@isoflow/isopacks` 0.0.10 (Isoflow by Mark Mankarious, MIT,
https://github.com/markmanx/isoflow), extracted from the package's data URIs and recoloured to graphite: every colour
becomes a grey of the same luminance (`#16`–`#CC`), the darkest ink becomes pure black. Used by the launcher's detail pane.
