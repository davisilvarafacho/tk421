OUTSIDE THE THEME

  • Status bar: show it, add the Clock and Page Zoom items in the toolbar editor; Vivaldi already prints load progress there, the mod only restyles it.
  • Tabs: close button on hover; tab bar on top; panel on the left, not floating.
  • Speed Dial monograms: no native option. Set a custom thumbnail per dial (monogram PNGs could be generated by a small script) or use the ::first-letter trick in the CSS below.
