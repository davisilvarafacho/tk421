WHAT THIS DIRECTION IS

  • Built only from what Settings → Themes exposes: survives every Vivaldi update, no vivaldi://experiments flag.
  • Frame, tab strip, panel bar and status bar are the island's black; toolbars and the active tab one step up (#0C0B0D).
  • No hue anywhere: focus, selection and load progress use the launcher's pale graphite. Page colours never leak into the chrome (accentFromPage: false, saturation limit 0).
  • Theme Engine friendly: the whole look is one generated settings.json, exported as a theme zip.
  • Out of reach without CSS mods: Geist as the UI font (Vivaldi uses the system sans; set via fontconfig instead), the start-page clock face, the 1 px hairline on the address field. Keys to be checked against a real export from 8.2.
