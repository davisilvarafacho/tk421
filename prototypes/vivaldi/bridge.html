REACHABLE WITHOUT CSS

  • Theme: black tab bar, surface toolbars and panels, graphite text, steel only on focus / selection / load progress, no page-tinted accent, no transparency or blur, slim scrollbars, 8 px corners everywhere.
  • Settings › Tabs: tab bar top; pinned tabs as icons; tab stacks compact. Address bar: top, highlight base domain on. Panel: left, panel toggle on the address bar. Status bar: shown. Start Page: Speed Dial, theme background, no thumbnails background image.
  • Toolbar editor: trim the address row to back, forward, reload, home · field · extensions, downloads, panel toggle, profile.
  • What that alone gives: a correct, quiet dark theme. It does not give floating pills, the centred address pill, chip tabs or the steel rails.

NEEDS CSS MODS SELECTORS UNVERIFIED

vivaldi://experiments › “Allow for using CSS modifications”, then Settings › Appearance › Custom UI Modifications → a folder holding tk421-bridge.css. Inspect the UI first (vivaldi://inspect/#apps › the browser window); class names below are from 6.x/7.x mods in the wild and may have moved in 8.x.

  • Deck + capsules: every chrome row on #0C0B0D; tab strip, nav group, toolbar group as black 28 px capsules with the 9 % hairline.
  • Chip tabs: 22 px tabs inside the capsule, hover/active = #1A1A21 chip, active adds an 18 × 2 px steel rail; loading tab shows a 1 px steel bar. Pinned tabs end with a divider.
  • Address pill: centred, max 720 px, widens to 960 px on focus (520 ms, island easing), steel line draws in under it; load progress as a hairline on its floor; suggestions card black, radius 14.
  • Panels: panel bar as a vertical capsule with a steel rail on the open panel; side panel as a floating black card, radius 14, Orbitron header.
  • Web view inset 6 px with 10 px corners and a hairline; status bar 26 px with a 20 px capsule (tiling, images, zoom, clock in Orbitron).
  • Speed Dial: black tiles + hairline, monogram via custom dial thumbnails (or hide thumbnails and enlarge the favicon), Orbitron clock and section labels.
  • Housekeeping: hide the window buttons (tiled under Hyprland), swap the browser logo in the menu button for the TK-421 mark, Geist as the UI font.
/* tk421-bridge.css  — sketch, Vivaldi 8.x, UNVERIFIED */
:root { --tk-ink:#000; --tk-hair:rgba(255,255,255,.09);
        --tk-chip:#1A1A21; --tk-deck:#0C0B0D; --tk-steel:var(--colorHighlightBg); }
#browser { font-family: Geist, sans-serif; }
#header, .mainbar, #footer { background: var(--tk-deck) !important; }

/* tab strip → one capsule; tabs → chips */
#tabs-container { padding: 4px 18px; }
#tabs-container .tab-strip { background: var(--tk-ink); border: 1px solid var(--tk-hair);
  border-radius: 14px; }
.tab-position .tab { background: transparent; border-radius: 8px; box-shadow: none; }
.tab-position .tab:hover,
.tab-position .tab.active { background: var(--tk-chip); }
.tab-position .tab.active::after { content: ""; position: absolute; left: 50%;
  bottom: 0; width: 18px; height: 2px; margin-left: -9px; background: var(--tk-steel); }
.tab-position.is-pinned:not(:has(+ .is-pinned)) { /* divider after pins */ }
.window-buttongroup { display: none; }

/* address field → centred pill, island morph on focus */
.UrlBar-AddressField { height: 28px; max-width: 720px; margin-inline: auto;
  background: var(--tk-ink); border: 1px solid var(--tk-hair); border-radius: 14px;
  transition: max-width 520ms cubic-bezier(.22,1,.36,1); }
.UrlBar-AddressField:focus-within { max-width: 960px;
  box-shadow: inset 0 -1px 0 var(--tk-steel); }
.UrlBar-AddressField .pageload-indicator { background: var(--tk-steel); height: 1px; }
.OmniDropdown { background: var(--tk-ink); border-radius: 14px; }

/* panels */
#panels-container #switch { /* 7.x+: .toolbar-panel? */
  background: var(--tk-ink); border: 1px solid var(--tk-hair); border-radius: 14px; }
#panels-container .panel-group { margin: 6px 0 8px; border-radius: 14px;
  background: var(--tk-ink); border: 1px solid var(--tk-hair); }
#webview-container .webpageview { margin: 6px 18px 8px 0; border-radius: 10px;
  overflow: hidden; box-shadow: 0 0 0 1px var(--tk-hair); }

/* speed dial */
.startpage .dial { background: var(--tk-ink); border: 1px solid var(--tk-hair);
  border-radius: 14px; }
.startpage .dial:hover { background: var(--tk-chip); }

Risks: Vivaldi's UI is its own React app; class names and DOM nesting change between majors (7.0's redesign moved the toolbars and the Speed Dial dashboard). Tab sizes and positions are computed in JS and written inline, so forcing heights or margins can make tabs overlap or clip; prefer padding on containers over sizing .tab. The mods fail silently after an update (the chrome falls back to the plain theme, which is why the theme alone must look right), and the experiments flag could be renamed. Keep the file small and comment each block with the Vivaldi version it was checked on.
