# Isometric objects (Isoflow)

Icons of the `isoflow` collection in `@isoflow/isopacks` 0.0.10 (Isoflow by Mark Mankarious, MIT,
https://github.com/markmanx/isoflow), extracted from the package's data URIs and recoloured to graphite: every colour
becomes a grey of the same luminance (#16-#CC), the darkest ink becomes pure black. The full set of 36 is in
`prototypes/launcher/iso/`. Used by the launcher's detail pane: `block` is the plinth, the others are picked by
`launcher/logic.js` (`isoFor`, `COMMANDS`).
